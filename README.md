# Flask Blog Application

A simple **Blog Web Application** built using **Flask** that allows users to create, edit, and delete blog posts.
This project demonstrates backend development concepts like **routing, forms, templates, and database integration**.

---

## 🚀 Features

* Create blog posts
* View all posts
* Read individual posts
* Edit posts
* Delete posts
* Form validation using Flask-WTF
* Clean template-based UI with Jinja2
* SQLite database support

## ⚙️ Installation

Clone the repository

```
git clone https://github.com/shin0biX/flask-blog.git
cd flask-blog
```

Create a virtual environment

```
python -m venv venv
```

Activate the virtual environment

Mac / Linux

```
source venv/bin/activate
```

Windows

```
venv\Scripts\activate
```

Install dependencies

```
pip install -r requirements.txt
```

---

## ▶️ Running the Application

Run the Flask server

```
python main.py
```

Open your browser

```
http://127.0.0.1:5000
```
